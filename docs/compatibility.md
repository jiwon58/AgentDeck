# Agent compatibility

## Native Windows Team

The Team option targets Windows x64, GJC 0.10.2 and the pinned psmux 3.4.0 binary. Deck starts GJC inside a fresh multiplexer session. GJC discovers the real pane and registers its Team ownership metadata through the upstream runtime. This avoids the unsupported GJC-managed `--tmux` launch path, which can reject native Windows session identity. Other GJC versions and other harnesses require separate Team verification. [GJC 0.10.2 Team runtime](https://github.com/Yeachan-Heo/gajae-code/blob/v0.10.2/packages/coding-agent/src/gjc-runtime/team-runtime.ts) · [GJC 0.10.2 Team skill](https://github.com/Yeachan-Heo/gajae-code/blob/v0.10.2/packages/coding-agent/src/defaults/gjc/skills/team/SKILL.md)

The compiled GJC 0.10.2 worker launcher can resolve to a Bun virtual path on Windows. Deck supplies the approved GJC binary via `GJC_TEAM_WORKER_COMMAND`, which takes precedence in that release, and points GJC’s multiplexer commands at the packaged psmux executable. GJC retains control of Team tasks, working trees and worker model configuration.

Manual GJC runtimes use GJC's provider configuration. GJC presets can prepare a model configuration and select a history location for reviewed versions. Resume opens the native picker using `--resume`. Both tagged GJC READMEs document `startup.checkUpdate=false` to suppress the notify-only startup check. The v0.10.2 README describes an npm release check, and v0.20.0 describes GitHub. The v0.20.0 CLI also documents `GJC_MODEL_PRESET_REGISTRY_DISABLED=1`. Claude Code documents `DISABLE_AUTOUPDATER` and `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`. A Hermes version-independent updater control remains unverified. See [GJC preset compatibility](gjc-presets.md#version-compatibility).

The GJC files were matched against GitHub release SHA-256 values before running help and version. The v0.10.2 digest was `31fed0cde93664dde8f6acea0822f14c5e28e5ec42697b3699c2609257b8f6ab`. The v0.20.0 digest was `625f9a8c6086c56cb910ae6ecaf8b20abf5d701cc214816ce0159165b606d9fb`. Both binaries were also registered and launched in Agent Deck’s packaged WebView smoke test. Each reached its interactive TUI in a temporary configuration directory with startup update checks disabled. Both tagged CLI parsers accept standalone --resume for the interactive history picker. Claude and Hermes documentation was reviewed without a real Agent execution test.

## Keyboard focus

Deck shortcuts apply to its toolbar, session list and tab strip. Terminal focus sends shortcuts to the harness. Deck preserves Alt as a distinct modifier for the arrow keys, keeps Shift+Tab, Ctrl+T and Ctrl+W in the terminal, and encodes modified Enter for the supported newline actions. Agent remaps and operating-system-reserved shortcuts follow the harness and Windows respectively.
