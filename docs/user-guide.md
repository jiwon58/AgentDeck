# User guide

## Monitor long-running GJC sessions

Use your normal GJC session and start ultragoal inside that terminal using the workflow supported by your GJC build. Deck's terminal tools run over the current native ConPTY sessions and require no tmux or Team setup. **Next reply** cycles through running sessions Deck recognizes as awaiting a response. **Sessions** (or **Ctrl+K** while a Deck control has focus) searches names, paths, agents, and session status. In the sidebar, **Group by project** groups matching working directories, and the star pins a saved session. Deck saves only these layout preferences.

**Side by side** shows two existing terminals. Click a pane to focus its input, or enable **Read-only** in that pane to review output while the agent continues running. **Find** searches retained terminal output, with **Enter** and **Shift+Enter** cycling matches inside the search box. **Bookmark** marks the selected row or the top visible row in the main terminal buffer. **Latest** returns to the end. Searches and bookmarks live in the open tab's memory. Bookmarks expire when their lines leave scrollback.

**Settings → Install Agents** offers publisher downloads. Choose an existing destination directory. Claude Code downloads the current Windows x64 executable and checks its release-manifest SHA-256. Hermes downloads the official Windows bootstrap for a separate review and install action. The bootstrap provisions dependencies and may update Windows user PATH. Both flows hand the executable to **Agent Runtimes** for explicit trust and registration.

To reuse a Gajae-Code runtime, router, model and history policy, create a preset in **Settings → GJC Presets** and select it in **New Session**. See [GJC presets and session history](gjc-presets.md).

1. Open **Settings → Agent Runtimes**, select an Agent, browse to its installation root and select **Scan**. Use **Inspect** for a known executable or interpreter.
2. Select **Review**, compare the path and SHA-256, review any launcher arguments, and explicitly approve. The optional version probe runs the approved executable with the displayed argument array and a four-second process timeout. Unknown version formats are registered as Unverified. Use a different name to distinguish installations of the same version.
3. In **Local LLM Router**, enter the address, port and enabled APIs. Use an empty Anthropic base path for a gateway rooted at the host. **Test Connection** reports connectivity. Choose a **Model API** and select **Refresh models** to fetch its current catalog. Select a discovered model or enter an ID manually, then choose **Test model** to send a short inference request. Use **Use as default** followed by **Save profile** to save a model choice. Refreshing the catalog leaves the saved default as entered and flags it if it disappears. Use a temporary token if required.
4. Choose **New Session**. Select the runtime and working directory. For Claude, pick an Anthropic profile and provide its bearer token if required. For other CLIs, confirm the manually configured provider and API. Configure optional runtime bindings of the form `NAME=endpoint` or `NAME=model` to inject the selected value on every launch. For example, `VLLM_BASE_URL=endpoint` is available for reviewed GJC v0.20.0 discovery profiles. The Agent’s provider and transport still need to be configured for the installation.
5. Select **?** on the top toolbar to open **Keyboard shortcuts**. With focus on a Deck control in the toolbar, session sidebar or tab strip, use Ctrl+T for a new session, Ctrl+W to close a Deck tab, and Ctrl+Tab or Ctrl+Shift+Tab to switch tabs. Click inside the terminal to use the Agent’s keys. Right-click the terminal to copy selected text or paste.
6. Select a saved Gajae-Code session and choose **Resume Gajae-Code conversation**. Re-enter any custom Agent directory, session directory, credentials or other transient overrides required for that launch. Select the existing conversation in the picker. Deck attaches the new terminal process to the existing history row, and GJC appends messages to the selected conversation. **Restart as new process** starts a new session and adds its own history row.

Use **<** next to the sidebar's active session count to collapse the list. Use **>** on the collapsed sidebar to reopen it. The bottom-right status bar shows the Agent Deck version. The session list uses blue while a new terminal starts, purple for work in progress, amber for a response needed and green when the Agent run ends.

Gajae-Code sessions update automatically when supported host-status signals reach the terminal. A response-needed label stays visible until a later Agent signal or the terminal exits. A reported end of run means the Agent stopped working and its result can be checked. Older GJC versions and other Agents show the terminal process status when no Agent signal is available. [Version-by-version GJC compatibility](gjc-session-status.md)

To open a PowerShell tab, register your approved absolute PowerShell executable as Generic CLI. For Hermes, register its native executable shim or an absolute interpreter with the documented entry-point arguments for that installation. Deck supports one literal argument per line. Shell scripts may be used via an explicitly approved interpreter profile. Avoid including credentials in saved names, paths, dependency notes or arguments.

Router preferences and terminal appearance can be exported to JSON through Application & Offline Settings. Import creates disabled router profiles so each can be reviewed before enabling.
